What I learned:

This is the most implementation-focused transcript yet. While the previous speakers were discussing architectural visions and organizational restructuring, Steve Yegge here is showing concrete workflows, tools, and the actual bleeding edge of agentic coding in practice. The key insight: **the constraint has shifted from "can agents write code" to "how do you manage, coordinate, and iterate with agents at scale."**

Key themes I noticed:

1. **Validation is the New Bottleneck**: Static screenshots as source of truth. Multimodal comparison (screenshot-to-screenshot). The agent can't be trusted to say it's done. Every artifact needs continuous validation. This is fundamentally different from traditional software—you're not trusting the agent's self-assessment.

2. **85% Correctness as a Design Pattern**: Not "the agent is perfect" but "the agent is 85% correct, and iterating is faster than manual work." This reframes the entire development workflow. You're no longer writing; you're refining.

3. **Tracer Bullets for Unsticking**: When stuck (9-10 iterations with no progress), don't iterate on the original approach—find the thinnest end-to-end working path. This is a specific technique for redirecting stuck agents, not just general advice.

4. **Session Management is Critical**: Agents have amnesia between sessions. "Landing the plane" is a scripted cleanup and handoff protocol. Beads provides session-to-session memory. Without this, each session starts from zero—the agent asks "who are you?"

5. **Beads as the Missing Layer**: Not a planning tool, not a messaging tool. It's a persistent issue ledger that sits between future work (vague, months out) and past work (archived). Current work gets prioritized. This creates addressable work units that agents can reference and reason about.

6. **Inter-Agent Communication is Hard**: Multiple agents need to communicate (agent mail pattern). File reservations. Message passing. Jeffrey Emanuel's solution is emerging. This is the constraint Yegge hit when agents need to coordinate.

7. **Cost is Real and Visible**: AMP shows token costs. This matters for decision-making (use cheaper models for fast iteration, better models for debugging). The fact that users can see "$14 for one feature" changes behavior.

8. **Code Review Becomes the Bottleneck**: Once agents are 10x productive, the next constraint isn't writing code—it's reviewing it. Graphite has been doing AI code review for 3 years. This is the unsolved problem at scale.

9. **Multimodal Validation is Emerging**: Screenshots work. Video would be better (for game motion, for UI behavior over time). This suggests the next frontier is rich sensory feedback, not just text.

10. **Junior Developers Can Thrive**: The "death of the junior developer" claim was wrong. The job changed—it's now asking the right questions, validating, iterating. This is teachable and doesn't require decades of experience.

11. **Agents Are Amenable to Structure**: They love checklists, acceptance criteria, explicit protocols like "landing the plane." Their training biases them toward explicit completion. This is exploitable for workflow design.

12. **Cost Optimization Through Model Routing**: Use cheap/fast models for iteration, expensive models for code review. This is a real strategy that's emerging.
