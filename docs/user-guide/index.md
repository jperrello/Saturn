# User Guide

Saturn gives you AI access on your local network with zero configuration. If an administrator has set up Saturn, you can start chatting with AI models immediately — no API keys, no accounts, no setup.

## What you get

- **Web UI** — a browser-based chat interface with model selection, conversation history, and tool use
- **AI-powered apps** — any application on your network that supports OpenAI-compatible endpoints works automatically through Saturn
- **CLI access** — discover available services and grab endpoints from your terminal

## Prerequisites

You need two things:

1. **Python 3.10+** with Saturn installed: `pip install saturn-ai`
2. **A network where an administrator has already deployed Saturn services** — if you're unsure, run `saturn discover` and see if anything shows up

That's it. You don't need API keys, cloud accounts, or configuration files.
